## Overview
Spider Theme Suite isn't just another color scheme—it's an enterprise-grade cognitive coding environment. Built around human developer psychology rather than AI hype, this theme suite minimizes cognitive load, drastically reduces eye strain, and forces visual priority onto your active logic. Designed for developers who need sustained, deep focus for hours at a time.

## Key Benefits

🚀 **Color by Scope**: Drops the rainbow bracket noise. Instead, your semantic environment works with you, subtly tinting code based on scope depth so you instantly recognize where you are in the stack.
⚙️ **Deep Focus Panes**: Enforces flow state by aggressively dimming inactive panes, tree views, and terminals. Only the active editor remains in the cognitive foreground.
🛡️ **Cognitive Load Warnings**: Automatically drops the opacity of unused variables, shadowed declarations, and unreachable code into the background. Your brain only processes what actually executes.
🔀 **Actionable Tooltips**: Strips away visual clutter, borders, and noise from hover widgets. Type definitions and signatures remain crisp and immediately legible.
✨ **Chromostereopsis Engineered**: Prevents visual vibration (the harsh 3D effect of red/blue overlap) by clinically harmonizing Crimson and Teal tones for absolute visual stability.
